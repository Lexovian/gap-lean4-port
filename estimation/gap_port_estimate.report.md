### Caveats

- Estimates are order-of-magnitude planning figures, not bids.
- A faithful *verified* port is assumed (proofs of correctness), which is far slower than an unchecked transpile.
- Kernel memory management / GC largely maps onto the Lean runtime rather than being ported line-for-line; this is encoded as a high mathlib_leverage for the kernel layer.
- Documentation (.xml/.txt manuals) is reference material that informs specifications and is not itself ported.
